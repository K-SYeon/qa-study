# MySQL 설치

## 개요

MySQL과 MySQL Workbench를 설치하고 데이터베이스 실습 환경을 구성한다.

## 학습 목표

- MySQL의 기본적인 역할을 이해한다.
- MySQL Workbench를 설치하고 실행할 수 있다.
- MySQL 서버에 접속할 수 있다.

## 학습 내용

### 1. MySQL

MySQL은 관계형 데이터베이스 관리 시스템(RDBMS)이다.

데이터를 테이블 형태로 저장하고 SQL을 사용하여 데이터를 생성, 조회, 수정, 삭제할 수 있다.

### 2. MySQL Workbench

MySQL Workbench는 MySQL 데이터베이스를 GUI 환경에서 관리하고 SQL을 실행할 수 있는 도구이다.

이번 실습에서는 MySQL Workbench를 사용하여 데이터베이스와 테이블을 생성하고 SQL을 실행한다.

### 3. MySQL Workbench 접속

MySQL Workbench 실행 후 설정된 MySQL 서버의 비밀번호를 입력하여 접속한다.

접속 후 왼쪽 `SCHEMAS` 영역에서 데이터베이스를 확인할 수 있다.

## QA 활용

QA에서는 데이터베이스에 저장된 데이터를 직접 확인하여 기능 테스트 결과를 검증할 수 있다.

예를 들어 회원가입 테스트 후 DB에 회원 정보가 정상적으로 저장되었는지 확인할 수 있다.
