# DELETE

## 개요

`DELETE`는 Table에 저장된 데이터를 삭제할 때 사용하는 SQL 명령어이다.

## 학습 목표

- `DELETE`를 사용하여 데이터를 삭제할 수 있다.
- `WHERE`를 사용하여 삭제할 대상을 지정할 수 있다.
- 삭제 전과 삭제 후의 데이터를 비교할 수 있다.

## 학습 내용

### 1. 기본 문법

```sql
DELETE FROM 테이블명
WHERE 조건;
```

### 2. 삭제 전 데이터 확인

데이터를 삭제하기 전에 삭제 대상이 존재하는지 확인한다.

```sql
SELECT *
FROM users
WHERE id = 1;
```

삭제 대상 데이터가 1건 존재하는 것을 확인했다.

### 3. 데이터 삭제

```sql
DELETE FROM users
WHERE id = 1;
```

`id`가 1인 회원 데이터를 삭제한다.

### 4. 삭제 후 확인

삭제가 완료된 후 해당 데이터가 더 이상 존재하지 않는지 확인한다.

```sql
SELECT *
FROM users
WHERE id = 1;
```

결과: 0건

삭제된 데이터가 조회되지 않는 것을 확인했다.

### 5. 주의사항

`DELETE`에서 `WHERE` 조건을 생략하면 Table의 모든 데이터가 삭제될 수 있다.

```sql
DELETE FROM users;
```

따라서 데이터를 삭제할 때는 삭제할 대상을 정확하게 지정해야 한다.

## QA 활용

회원 탈퇴 기능을 테스트할 때 다음과 같이 DB에서 결과를 검증할 수 있다.

```text
회원 탈퇴
→ DELETE
→ SELECT
→ 해당 회원 존재 여부 확인
```

삭제 후 0건이 조회되면 DB에서 해당 회원 데이터가 정상적으로 삭제된 것으로 확인할 수 있다.
