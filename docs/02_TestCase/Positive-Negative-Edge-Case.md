# Positive / Negative / Edge Case

## Positive Case

Positive Case는 **정상적인 입력이나 상황에서 기능이 기대한 대로 동작하는지 검증하는 테스트**이다.

대부분의 기능 요구 사항을 검증하는 테스트가 이에 해당한다.

- 목적
  - 시스템이 정상적인 사용 흐름에서 정확하게 동작하는지 확인한다.
- 입력 값
  - 유효하고 일반적인 입력 값

**예시**

- 로그인 화면에서 올바른 ID와 비밀번호를 입력했을 때 정상적으로 로그인되는지 확인

---

## Negative Case

Negative Case는 **잘못된 입력이나 예외 상황에서 시스템이 오류를 적절하게 처리하는지 검증하는 테스트**이다.

사용자의 실수나 예외적인 상황을 고려하여 테스트를 설계한다.

- 목적
  - 잘못된 입력이나 시스템의 예외 상황에서 적절하게 처리되는지 확인한다.
- 입력 값
  - 잘못된 값 또는 비정상적인 입력 값

**예시**

- 회원가입 화면에서 ID를 입력하지 않았을 때 "ID를 입력하세요."와 같은 오류 메시지가 표시되는지 확인

---

## Edge Case

Edge Case는 **입력 값이나 조건이 한계점(경계값)에 가까울 때 시스템이 올바르게 동작하는지 검증하는 테스트**이다.

우선순위는 상대적으로 낮을 수 있지만, 경계 조건을 제대로 처리하지 못하면 예상하지 못한 오류가 발생할 수 있다.

- 목적
  - 최소값, 최대값, 경계값 등 시스템의 한계 상황에서 정상적으로 동작하는지 확인한다.
- 입력 값
  - 제한된 범위의 경계값 또는 입력 한계에 해당하는 값

**예시**

- Zoom 옵션 필드의 허용 범위가 0~18인 경우
  - 0
  - 18
  - -1
  - 19

---

## 비교

| 구분 | 확인 대상 |
|------|-----------|
| Positive Case | 정상적인 입력과 사용 흐름 |
| Negative Case | 잘못된 입력과 예외 상황 |
| Edge Case | 최소값, 최대값 등 경계 조건 |

---

## 정리

- Positive Case는 정상적인 입력과 상황에서 기능이 올바르게 동작하는지 확인하는 테스트이다.
- Negative Case는 잘못된 입력이나 예외 상황에서도 시스템이 적절하게 처리하는지 확인하는 테스트이다.
- Edge Case는 입력 범위의 경계값이나 한계 상황에서 시스템이 정상적으로 동작하는지 확인하는 테스트이다.
