# Postman

## 개요

Postman은 API를 요청하고 Response를 확인하며 API를 테스트할 수 있는 도구이다.

QA에서는 API Request를 관리하고, Environment와 Variables를 활용하여 테스트 환경과 값을 관리하며, Test Script를 통해 API Response를 자동으로 검증할 수 있다.

## 학습 목표

* Postman의 기본적인 사용 방법을 이해한다.
* Collection의 개념과 역할을 이해한다.
* Environment의 개념과 역할을 이해한다.
* Variables의 개념과 사용 방법을 이해한다.
* Test Script의 개념과 역할을 이해한다.
* API Response를 자동으로 검증하는 방법을 이해한다.
* QA에서 Postman을 활용하는 기본적인 방법을 이해한다.
