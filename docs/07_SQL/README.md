# 07_SQL

## 개요

SQL(Structured Query Language)은 데이터베이스(DB)에 저장된 데이터를 조회, 생성, 수정, 삭제하기 위한 언어이다.

QA는 화면(UI)이나 API 테스트뿐만 아니라 데이터베이스(DB)에 저장된 데이터를 직접 확인하여 테스트 결과를 검증해야 하는 경우가 많다. 따라서 SQL의 기본 문법을 이해하고 활용하는 것은 QA의 기본 역량 중 하나이다.

---

## 학습 목표

- SQL의 기본 개념 이해
- 데이터 조회(SELECT), 생성(INSERT), 수정(UPDATE), 삭제(DELETE) 방법 학습
- 조건 검색(WHERE), 정렬(ORDER BY), 그룹화(GROUP BY) 방법 이해
- JOIN을 이용한 여러 테이블 조회 방법 이해
- SQL을 활용한 QA 데이터 검증 방법 학습
