# SQL이란?

## SQL의 의미

SQL(Structured Query Language)은 데이터베이스(DB)에 저장된 데이터를 조회, 생성, 수정, 삭제하기 위한 언어이다.

---

## 데이터베이스(DB)란?

데이터를 저장하고 관리하는 공간이다.

예를 들어 회원가입을 하면 다음과 같은 과정으로 데이터가 저장된다.

```text
회원가입
    ↓
API 요청
    ↓
서버
    ↓
데이터베이스(DB)에 저장
```

---

## SQL 동작 과정

사용자가 SQL을 작성하면 데이터베이스(DB)가 요청을 처리한 후 결과를 반환한다.

```text
사용자
    ↓
SQL 작성
    ↓
데이터베이스(DB)
    ↓
결과 반환
```

예시

```sql
SELECT *
FROM users;
```

위 SQL은 `users` 테이블의 모든 데이터를 조회한다.

---

## SQL로 할 수 있는 작업

| 작업 | SQL |
|------|------|
| 조회 | SELECT |
| 생성 | INSERT |
| 수정 | UPDATE |
| 삭제 | DELETE |

---

## QA에서 SQL을 알아야 하는 이유

QA는 화면(UI)이나 API 테스트뿐만 아니라 데이터가 데이터베이스(DB)에 정상적으로 저장되었는지도 확인해야 한다.

예를 들어 회원가입 기능을 테스트하면

```text
회원가입
    ↓
API 요청
    ↓
201 Created
    ↓
DB 저장 여부 확인
```

데이터가 정상적으로 저장되었는지 SQL로 확인할 수 있다.

```sql
SELECT *
FROM users;
```

또는 회원가입에 사용한 이메일을 조건으로 특정 회원만 조회할 수도 있다.

```sql
SELECT *
FROM users
WHERE email = 'test@test.com';
```

---

## 핵심 정리

- SQL은 데이터베이스(DB)를 다루기 위한 언어이다.
- 데이터를 조회(SELECT), 생성(INSERT), 수정(UPDATE), 삭제(DELETE)할 수 있다.
- QA는 SQL을 이용하여 테스트 결과를 데이터베이스에서 직접 검증할 수 있다.
- API 테스트와 SQL을 함께 사용하면 문제의 원인을 더욱 정확하게 분석할 수 있다.

---

## 전체 동작 흐름

```text
사용자
    ↓
클라이언트(UI)
    ↓
API
    ↓
서버
    ↓
SQL
    ↓
데이터베이스(DB)
```
