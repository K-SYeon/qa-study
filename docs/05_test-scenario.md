# Test Scenario

## 1. Test Scenario란?

테스트 대상이 되는 기능이나 상황을 정의하는 것이다.

테스트를 진행하기 전에 어떤 기능을 어떤 관점에서 확인할지 정하는 역할을 한다.

---

## 2. Test Scenario 작성 목적

- 테스트 범위를 정의하기 위해
- 테스트해야 할 기능을 파악하기 위해
- 테스트 방향을 정하기 위해

---

## 3. Test Scenario와 Test Case의 차이

| 구분 | Test Scenario | Test Case |
| --- | --- | --- |
| 목적 | 테스트할 대상과 상황 정의 | 실제 테스트 수행 방법 정의 |
| 범위 | 큰 단위 | 세부 단위 |
| 관계 | 여러 Test Case를 포함 | Scenario에 포함되는 항목 |

---

## 4. 정리

Test Scenario는 테스트의 전체적인 방향을 정하고,
Test Case는 해당 Scenario를 검증하기 위한 상세한 테스트 항목이라고 이해했다.
