# 버그 리포트

## 개요

QA 테스트 과정에서 결함(Bug)을 기록하고 관리하는 방법을 학습하기 위한 문서입니다.

## 실습 목적

실제 테스트에서는 모든 Test Case가 정상적으로 동작하여 결함이 발견되지 않았습니다.
따라서 본 문서는 **실제 테스트 결과와는 무관한 가상의 결함 시나리오**를 기반으로 Bug Report 작성 방법을 학습하기 위해 작성되었습니다.

## 학습 내용

- Bug Report 작성 방법
- 결함 제목 작성
- 재현 절차(Steps to Reproduce) 작성
- 기대 결과(Expected Result)와 실제 결과(Actual Result) 작성
- Severity(심각도) 분류
- Priority(우선순위) 분류
- Status(상태) 관리

## 테스트 환경

- Windows 10
- Chrome
