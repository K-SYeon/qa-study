# 버그 리포트

## 개요

QA 테스트 과정에서 발견한 결함을 정리하고 관리하는 방법을 학습하기 위한 문서입니다.

## 실습 목적

실제 테스트에서 발견한 결함이 아닌 가상의 결함 상황을 활용하여 Bug Report 작성 방법을 학습합니다.

## 학습 내용

- Bug Report 작성 방법
- 결함 제목 작성
- 재현 절차 작성
- 기대 결과와 실제 결과 작성
- Severity(심각도) 분류
- Priority(우선순위) 분류
- Status(상태) 관리

## 테스트 환경

- Windows 10
- Chrome

## 파일

- Bug_Report.xlsx
