# STLC (Software Testing Life Cycle)

## 1. STLC란?

STLC(Software Testing Life Cycle)는 소프트웨어 테스트 생명주기이다.

SDLC 과정에서 QA가 수행하는 역할과 테스트 과정을 단계별로 구분한 것이다.

SDLC가 "어떤 제품을 만들 것인가"에 초점을 둔다면,
STLC는 "제품을 어떻게 테스트할 것인가"에 초점을 둔다.

---

# 2. STLC 단계

## 1) 요구 사항 분석 단계

개발될 제품을 확인하고 테스트 가능한 요구 사항을 식별하는 단계이다.

### QA 역할

- 기능 파악
- 테스트 범위 선정
- 요구 사항 부족 부분 확인
- 기획 및 개발 팀에 의견 전달

예)

장바구니 상품 개수를 5개로 제한했을 때,
6개를 추가하려는 경우 사용자에게 어떻게 안내할지 확인

---

## 2) 테스트 설계 단계

테스트 방법과 전략을 계획하는 단계이다.

### 확인 사항

- 테스트 환경
- 필요한 리소스
- 테스트 일정
- 테스트 도구

필요한 경우 테스트 계획서를 작성한다.

---

## 3) 테스트 케이스 개발 단계

테스트 계획을 기반으로 실제 테스트 케이스를 작성하는 단계이다.

### QA 역할

- 테스트 케이스 작성
- 자동화 테스트 케이스 작성
- 요구 사항 변경 사항 확인
- 개발 과정과 협업하며 테스트 기준 유지

---

## 4) 테스트 환경 구축 단계

테스트 수행을 위한 환경을 준비하는 단계이다.

개발 환경과 분리된 테스트 환경에서 진행하는 것이 이상적이며,
상황에 따라 환경은 변경될 수 있다.

---

## 5) 테스트 실행 단계

작성한 Test Case를 기반으로 테스트를 수행하는 단계이다.

### QA 역할

- 테스트 수행
- 결과 확인
- 결함 발견 및 보고
- 개발 팀과 협업하여 결함 수정 진행

---

## 6) 테스트 종료 단계

테스트 종료 기준을 확인하고 결과를 정리하는 단계이다.

### QA 역할

- 테스트 결과 리포트 작성
- 종료 기준 충족 여부 확인
- 남은 결함 및 이후 수정 일정 확인

---

# 3. 정리

STLC는 QA가 제품을 어떤 방식으로 검증할지 단계별로 정의한 과정이다.

테스트는 단순히 오류를 찾는 과정이 아니라,
요구 사항 분석부터 종료 단계까지 품질을 관리하는 과정이라고 이해했다.
