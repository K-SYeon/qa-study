# JIRA

## 개요

JIRA는 소프트웨어 개발 프로젝트에서 업무와 이슈를 관리하기 위한 협업 도구이다.

QA에서는 테스트 중 발견한 Bug를 Issue로 등록하고, 수정 및 재테스트 과정을 관리하는 데 활용할 수 있다.

## 학습 목표

- JIRA의 기본 개념과 구조를 이해한다.
- Project와 Issue의 관계를 이해한다.
- Issue Type의 종류와 역할을 이해한다.
- Bug Report와 JIRA Issue의 관계를 이해한다.
- Priority와 Severity의 차이를 이해한다.
- Status와 Workflow의 개념을 이해한다.
- QA에서 JIRA를 활용하는 기본적인 흐름을 이해한다.

## 학습 내용

- JIRA의 정의와 기본 구조
- JIRA 설치 및 기본 설정
- Project
- Issue
- Issue Type
- Bug Report
- Priority
- Severity
- Status
- Workflow
- QA에서의 JIRA 활용
