# Install

## 개요

JIRA Cloud를 사용하기 위한 계정을 생성하고 초기 환경을 설정한다.

JIRA는 별도의 프로그램을 설치하는 방식이 아니라 웹 브라우저를 통해 사용할 수 있으며, Atlassian 계정을 이용하여 로그인한다.

## 학습 목표

- JIRA Cloud의 기본 사용 방식을 이해한다.
- Atlassian 계정을 생성하고 JIRA에 로그인한다.
- JIRA 학습을 위한 Space를 생성한다.
- 초기 설정을 진행하고 기본 보드 화면을 확인한다.

## 학습 내용

### 1. JIRA Cloud

JIRA Cloud는 별도의 프로그램을 설치하지 않고 웹 브라우저에서 사용하는 JIRA 서비스이다.

따라서 PC에 JIRA 프로그램을 별도로 설치할 필요가 없다.

기본적인 사용 과정은 다음과 같다.

```text
웹 브라우저
    ↓
JIRA Cloud 접속
    ↓
Atlassian 계정 로그인
    ↓
JIRA 환경 생성
    ↓
JIRA 사용
```

### 2. Atlassian 계정 생성 및 로그인

JIRA를 사용하기 위해 Atlassian 계정을 생성하고 로그인한다.

Atlassian 계정을 통해 JIRA Cloud에 접속할 수 있다.

### 3. JIRA 환경 생성

JIRA 초기 설정 과정에서 사용할 업무 유형으로 `Software development`를 선택했다.

팀에서 Jira를 사용하는 방식은 `Run sprints`를 선택했다.

코딩 에이전트 선택 단계에서는 `Codex`를 선택했다.

### 4. Space 생성

JIRA에서 팀의 업무를 관리할 Space를 생성했다.

학습용 Space 이름은 다음과 같이 설정했다.

```text
QA Testing
```

### 5. 기본 보드 확인

Space 생성 후 기본 보드가 생성된 것을 확인했다.

보드는 다음과 같은 상태로 구성되어 있다.

```text
To Do
   ↓
In Progress
   ↓
Done
```

각 상태는 업무가 진행되는 현재 상태를 나타낸다.

### 6. 기본 화면 확인

JIRA의 `QA Testing` Space에서 다음 메뉴를 확인했다.

- 요약
- 백로그
- 보드
- 문서
- 개발

현재 학습에서는 보드를 통해 업무의 상태가 어떻게 관리되는지 확인했다.

### 7. 팀원 초대

JIRA 초기 설정 과정에서 팀원을 초대할 수 있었으나, 개인 학습용으로 사용하기 때문에 별도의 팀원 초대는 진행하지 않았다.

## 학습 결과

- JIRA Cloud 사용 환경을 생성했다.
- Atlassian 계정을 이용하여 JIRA에 로그인했다.
- `QA Testing` Space를 생성했다.
- 기본 보드와 `To Do`, `In Progress`, `Done` 상태를 확인했다.
- JIRA의 기본 메뉴 구조를 확인했다.
