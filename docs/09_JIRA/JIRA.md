# JIRA

## 개요

JIRA는 소프트웨어 개발 프로젝트에서 업무와 이슈를 관리하기 위한 협업 도구이다.

QA에서는 테스트 과정에서 발견한 버그를 등록하고, 담당자를 지정하며, 수정 상태를 추적하고, 재테스트하는 등의 업무에 활용할 수 있다.

## 학습 목표

- JIRA의 개념을 이해한다.
- JIRA에서 사용하는 기본 용어를 이해한다.
- Issue의 개념을 이해한다.
- QA 업무에서 JIRA가 어떻게 활용되는지 이해한다.
- 테스트부터 버그 수정 및 재테스트까지의 업무 흐름을 이해한다.

## 학습 내용

### 1. JIRA란?

JIRA는 소프트웨어 개발 프로젝트에서 **업무와 이슈를 관리하기 위한 협업 도구**이다.

QA 관점에서는 특히 버그를 등록하고, 담당자를 지정하고, 수정 상태를 추적하며, 재테스트하는 과정에서 많이 사용한다.

QA 업무에서 JIRA를 활용하는 기본적인 흐름은 다음과 같다.

```text
테스트 실행
    ↓
버그 발견
    ↓
Bug Report 작성
    ↓
JIRA에 Issue 등록
    ↓
개발자에게 전달
    ↓
수정
    ↓
QA 재테스트
    ↓
PASS / 재오픈
```

### 2. JIRA에서 Issue란?

JIRA에서 **Issue**는 단순히 Bug만을 의미하지 않는다.

프로젝트에서 관리해야 하는 **작업이나 문제를 하나의 단위로 등록한 것**을 Issue라고 한다.

예를 들어 다음과 같은 작업이나 문제를 Issue로 등록할 수 있다.

- 로그인 기능 구현
- 회원가입 기능 수정
- 로그인 버튼 UI 수정
- 로그인 시 오류 발생
- 비밀번호 찾기 기능 테스트

따라서 **Bug도 Issue의 한 종류**라고 이해할 수 있다.

### 3. JIRA의 기본 구조

JIRA에서는 프로젝트의 업무를 Issue 단위로 관리한다.

```text
Project
    ↓
Issue
    ├── Issue Type
    ├── Assignee
    ├── Priority
    ├── Status
    └── Workflow
```

| 용어 | 의미 |
|---|---|
| **Project** | 업무를 관리하는 프로젝트 공간 |
| **Issue** | 관리해야 할 작업이나 문제 |
| **Issue Type** | Issue의 종류 |
| **Assignee** | 해당 Issue를 담당하는 사람 |
| **Priority** | 처리 우선순위 |
| **Status** | 현재 진행 상태 |
| **Workflow** | Issue가 상태별로 이동하는 과정 |

각 항목은 이후 학습 과정에서 자세히 다룬다.

### 4. QA에서 JIRA를 사용하는 이유

QA는 Bug Report를 작성하는 것에서 끝나는 것이 아니라, 발견한 결함을 개발팀에 전달하고 수정 과정을 추적하며 수정된 기능을 다시 테스트해야 한다.

실제 업무에서는 Bug Report를 별도의 문서로만 전달하기보다 JIRA에 Issue로 등록하여 팀원들이 함께 관리하는 경우가 많다.

따라서 JIRA는 QA 업무 과정에서 발생하는 **작업과 결함을 관리하고 진행 상황을 추적하기 위한 도구**로 활용할 수 있다.

### 5. QA 업무와 JIRA의 관계

지금까지 학습한 QA 과정을 JIRA와 연결하면 다음과 같이 볼 수 있다.

```text
Test Case
    ↓
테스트 실행
    ↓
결함 발견
    ↓
Bug Report 작성
    ↓
JIRA Issue 등록
    ↓
개발자 수정
    ↓
QA Retest
    ↓
PASS → 종료
FAIL → 재오픈
```

이를 통해 JIRA가 QA 테스트 자체를 수행하는 도구가 아니라, **테스트 과정에서 발생하는 업무와 결함을 관리하는 도구**라는 것을 이해할 수 있다.

## 핵심 정리

- JIRA는 소프트웨어 개발 프로젝트의 업무와 이슈를 관리하는 협업 도구이다.
- JIRA에서 Issue는 관리해야 할 작업이나 문제를 의미한다.
- Bug는 JIRA에서 관리할 수 있는 Issue의 한 종류이다.
- QA는 JIRA를 이용하여 발견한 결함을 등록하고 수정 과정을 추적할 수 있다.
- JIRA는 테스트 실행부터 Bug 등록, 수정, 재테스트까지의 QA 업무 흐름을 관리하는 데 활용할 수 있다.
