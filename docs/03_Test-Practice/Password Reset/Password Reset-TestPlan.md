# 비밀번호 찾기 기능 요구사항

## 기능

사용자는 아이디, 전화번호(또는 이메일), 이름을 입력하고 본인 인증을 완료한 후 새로운 비밀번호로 변경할 수 있다.

## 화면 구성

* 아이디 입력창
* 전화번호 또는 이메일 입력창
* 이름 입력창
* 인증번호 입력창
* 새 비밀번호 입력창
* 인증번호 전송 버튼
* 비밀번호 변경 버튼

## 요구사항

1. 사용자는 아이디, 전화번호(또는 이메일), 이름을 입력하여 본인 확인을 진행할 수 있다.
2. 올바른 사용자 정보를 입력하면 인증번호를 전송할 수 있다.
3. 인증번호 인증을 완료한 경우에만 새 비밀번호를 설정할 수 있다.
4. 새 비밀번호가 조건을 만족하면 비밀번호가 변경되고 로그인 화면으로 이동한다.
5. 아이디를 입력하지 않으면 필수 입력 오류 메시지를 표시한다.
6. 전화번호 또는 이메일을 입력하지 않으면 필수 입력 오류 메시지를 표시한다.
7. 이름을 입력하지 않으면 필수 입력 오류 메시지를 표시한다.
8. 인증번호를 입력하지 않으면 필수 입력 오류 메시지를 표시한다.
9. 새 비밀번호를 입력하지 않으면 필수 입력 오류 메시지를 표시한다.
10. 전화번호 또는 이메일 형식이 올바르지 않으면 입력값 형식 오류 메시지를 표시한다.
11. 새 비밀번호가 비밀번호 조건을 만족하지 않으면 비밀번호 조건 미충족 메시지를 표시한다.
12. 존재하지 않는 아이디 또는 일치하지 않는 사용자 정보를 입력하면 다음 단계로 진행할 수 없다.
