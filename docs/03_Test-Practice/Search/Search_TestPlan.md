# Search Test Plan

## 1. 테스트 대상

네이버 검색 기능

## 2. 테스트 목적

검색어를 입력하여 검색했을 때 검색 기능이 정상적으로 동작하는지 확인한다.

## 3. 테스트 범위

다양한 검색어 입력에 따른 검색 기능을 확인한다.

* 정상적인 검색어 입력
* 검색어 미입력
* 존재하지 않는 검색어 입력
* 특수문자 입력
* 공백 입력
* 긴 검색어 입력
* 영문 검색어 입력
* 숫자 입력

## 4. 테스트 방법

네이버 검색창에 각각의 검색어를 입력한 후 검색 버튼을 클릭하여 검색 결과가 정상적으로 표시되는지 확인한다.

## 5. 테스트 환경

* 대상: 네이버 웹 검색
* 브라우저: Chrome
* 테스트 방식: 수동 테스트
