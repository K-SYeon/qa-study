# 검색 기능 요구사항

## 기능

사용자는 검색어를 입력하여 원하는 정보를 검색할 수 있다.

## 화면 구성

* 검색어 입력창
* 검색 버튼
* 검색 결과

## 요구사항

1. 사용자가 검색어를 입력하고 검색 버튼을 클릭하면 입력한 검색어와 관련된 검색 결과를 표시한다.
2. 검색어를 입력하지 않고 검색하면 검색 결과를 표시하지 않는다.
3. 존재하지 않는 검색어를 입력하면 검색어와 관련성이 있는 검색 결과를 표시한다.
4. 특수문자가 포함된 검색어를 입력하여 검색할 수 있다.
5. 공백만 입력하여 검색하면 검색 결과를 표시하지 않는다.
6. 긴 검색어를 입력하여 검색할 수 있다.
7. 영문 검색어를 입력하여 검색할 수 있다.
8. 숫자 검색어를 입력하여 검색할 수 있다.
