# Test Case

## 1. Test Case란?

특정 기능이 정상적으로 동작하는지 확인하기 위해 작성하는 테스트 항목이다.

테스트를 수행하기 위한 조건과 절차, 예상 결과를 정리한다.

---

## 2. Test Case 작성 목적

- 테스트 기준을 명확하게 하기 위해
- 테스트 결과를 확인하기 위해
- 동일한 조건으로 테스트하기 위해

---

## 3. Test Case 구성

Test Case는 테스트를 수행하기 위한 정보를 포함한다.

주요 항목:

- 테스트 대상
- 테스트 조건
- 테스트 절차
- 예상 결과

---

## 4. 정리

Test Case는 Test Scenario에서 정의한 테스트 범위를 실제로 검증하기 위한 상세 항목이다.

테스트를 진행할 때 동일한 기준으로 확인할 수 있도록 테스트 과정과 결과를 정리하는 것이 중요하다.
