# HTTP Status Code

## HTTP Status Code의 의미

HTTP Status Code는 클라이언트의 요청을 서버가 어떻게 처리했는지 결과를 알려주는 3자리 숫자 형식의 응답 코드이다.

예시

```text
클라이언트
      ↓
HTTP Request
      ↓
서버(Server)
      ↓
HTTP Response
      ↓
200 OK
```

## 상태 코드 분류

| 상태 코드 | 의미 |
| ---------- | ---------------------------- |
| 2xx | 요청 성공 |
| 3xx | 리다이렉션(다른 주소로 이동) |
| 4xx | 클라이언트 요청 오류 |
| 5xx | 서버 오류 |

---

## 200 OK

요청이 정상적으로 처리되었다.

예시

- 로그인 성공
- 검색 성공
- 상품 조회 성공

---

## 201 Created

새로운 데이터가 정상적으로 생성되었다.

예시

- 회원가입 성공
- 게시글 등록 성공

---

## 204 No Content

요청은 성공했지만 반환할 데이터가 없다.

예시

- 삭제 성공
- 로그아웃 성공(API에 따라 사용)

---

## 400 Bad Request

클라이언트가 잘못된 요청을 보냈다.

예시

- 필수 입력값 누락
- 잘못된 형식의 데이터 입력

---

## 401 Unauthorized

인증이 필요하거나 인증에 실패했다.

예시

- 로그인하지 않은 사용자가 접근
- 인증 토큰이 없거나 만료됨

---

## 403 Forbidden

권한이 없어 접근할 수 없다.

예시

- 일반 사용자가 관리자 페이지에 접근

---

## 404 Not Found

요청한 URL 또는 리소스를 찾을 수 없다.

예시

- 존재하지 않는 사용자 조회
- 잘못된 URL 요청

---

## 500 Internal Server Error

서버 내부에서 오류가 발생했다.

예시

- 서버 프로그램 오류
- 데이터베이스 오류

---

## QA에서 HTTP Status Code를 알아야 하는 이유

QA는 HTTP Status Code를 확인하여 문제의 원인을 빠르게 분석할 수 있다.

예를 들어 로그인 API를 테스트했을 때

- **200 OK** : 로그인이 정상적으로 처리되었다.
- **401 Unauthorized** : 인증 문제가 발생했다.
- **500 Internal Server Error** : 서버 내부 오류가 발생했다.

HTTP Status Code를 이해하면 API 테스트 결과를 분석하고, 문제의 원인을 보다 정확하게 파악할 수 있다.

---

## 핵심 정리

- HTTP Status Code는 서버가 요청 처리 결과를 알려주는 응답 코드이다.
- 2xx는 요청 성공, 3xx는 리다이렉션, 4xx는 클라이언트 오류, 5xx는 서버 오류를 의미한다.
- QA는 Status Code를 확인하여 문제의 원인을 빠르게 분석할 수 있다.
- 신입 QA는 **200, 201, 204, 400, 401, 403, 404, 500**을 우선적으로 숙지하는 것이 좋다.
