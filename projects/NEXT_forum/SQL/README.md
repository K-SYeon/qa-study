
# SQL

## 개요
QA 업무에 필요한 SQL 기본 문법을 학습하고, 데이터 조회 및 검증에 활용할 수 있도록 학습 내용과 실습 결과를 정리한다.

## 학습 목표
- SQL을 활용하여 데이터 조회 및 조건별 필터링을 수행한다.
- 집계 함수와 JOIN을 사용하여 데이터를 분석한다.
- 서브쿼리와 조건문을 활용하여 필요한 데이터를 검증한다.
- SQL 쿼리의 실행 결과를 확인하고 해석한다.

## 학습 내용
- 데이터 조회 및 조건 설정
- 정렬 및 데이터 제한
- 집계 함수와 그룹화
- JOIN 및 서브쿼리
- 조건문과 NULL 처리
- 문자열 및 숫자 함수
- 날짜 함수
- 윈도우 함수
