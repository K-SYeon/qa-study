# NEXT_forum QA 프로젝트

## 프로젝트 개요

NEXT_forum 웹 애플리케이션을 대상으로 주요 기능의 정상 동작 여부를 검증한 QA 실전 프로젝트입니다.

테스트 시나리오와 테스트 케이스를 작성하고, 수동 테스트 및 Playwright 자동화 테스트를 수행하여 기능별 오류와 개선이 필요한 사항을 확인했습니다.

발견한 결함은 Bug Report로 작성하고, 테스트 결과와 결함 내역을 문서화했습니다.

## 프로젝트 목표

- 웹 애플리케이션의 주요 기능 및 사용자 흐름 검증
- 테스트 시나리오와 테스트 케이스 작성
- 수동 테스트를 통한 기능별 정상 동작 여부 확인
- Playwright를 활용한 테스트 자동화
- 발견한 결함의 재현 절차 및 기대 결과, 실제 결과 문서화
- 테스트 결과를 바탕으로 QA 산출물 작성 및 관리

## 테스트 환경

| 항목 | 환경 |
|---|---|

| Browser | Google Chrome |
| Test Site | NEXT_forum |
| Test URL | http://localhost:3000 |
| Automation Tool | Playwright |

## 테스트 범위

| 테스트 영역 | 주요 테스트 항목 |
|---|---|
| 회원가입 | 정상 가입, 필수 입력값, 중복 아이디 |
| 로그인 / 로그아웃 | 정상 로그인, 로그아웃, 페이지 이동 |
| 게시글 | 게시글 작성, 조회, 수정, 삭제 |
| 댓글 | 댓글 작성, 좋아요 |
| 관리자 기능 | 다른 사용자의 게시글 수정 및 삭제 |
| UI | 메인 화면, 로그인 상태, 화면 모드 |
| 페이지 이동 | 메뉴 및 페이지 이동 |

## 테스트 수행 방법

1. 테스트 시나리오 작성
2. 테스트 케이스 및 테스트 데이터 작성
3. 수동 테스트 수행 및 실제 결과 기록
4. 발견한 결함을 Bug Report로 작성
5. JIRA를 활용한 결함 관리
6. Playwright를 활용한 주요 기능 자동화 테스트
7. 자동화 테스트 결과 확인 및 테스트 케이스 반영

## 테스트 결과

### Playwright 자동화 테스트

- 자동화 테스트 실행 결과: **18 Passed / 0 Failed**
- 주요 기능에 대한 자동화 테스트 수행
- 중복 아이디 가입 등 기존 결함 재현 테스트 포함

※ 자동화 테스트의 Passed는 작성한 테스트 코드가 정상적으로 실행되고 검증을 완료했다는 의미이며, 애플리케이션의 모든 기능이 정상이라는 의미는 아닙니다.

## 프로젝트 산출물

- Test Scenario : 테스트 시나리오
- Test Case : 테스트 케이스 및 실행 결과
- Bug Report : 발견한 결함 및 재현 절차
- Playwright : 자동화 테스트 코드 및 학습 내용

## 프로젝트 회고

실제 웹 애플리케이션을 대상으로 테스트 시나리오와 테스트 케이스를 작성하고, 수동 테스트 및 자동화 테스트를 수행하며 QA 업무의 전반적인 흐름을 경험했습니다.

또한 단순히 테스트 성공 여부를 확인하는 것뿐만 아니라, 요구사항과 실제 동작의 차이를 파악하고 이를 결함으로 기록하는 과정의 중요성을 배웠습니다.
